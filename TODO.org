Findings from a code review of ~vice-mode.el~ (2026-09-24).

** Bugs

- [ ] Unbalanced input signals ~scan-error~. ~forward-sexp~ in
  ~vice--pair-bounds~ and ~vice--string-bounds~ errors on an unclosed
  pair or string (e.g. ~da(~ in ~(foo (bar~), which is common while
  typing. Return nil instead (~ignore-errors~) so dispatch reports "no
  object at point". Add a test.

** Deferred

- [ ] Default ~vice-key-prefix~ (~C-c v~) is in the ~C-c <letter>~
  space reserved for users by the Emacs key binding conventions.
  Already accepted on MELPA as is; revisit if it becomes an issue
  (e.g. default to nil and document binding it).

** Simplifications

- [X] Dead branch in ~vice--pair-bounds~ for ~i~: a balanced pair always
  has ~end >= start + 2~, so the ~if~ equals ~(list (1+ start) (1- end))~.
- [X] ~vice--pair-bounds~ and ~vice--string-bounds~ share "go to start,
  ~forward-sexp~, a/i". Extract a ~vice--sexp-bounds (start modifier)~
  helper; the unbalanced-input fix then lives in one place.
- [ ] Drop the four one-line operator wrappers (~vice--op-kill~,
  ~vice--op-save~, ~vice--op-comment~, ~vice--op-indent~) and put
  ~kill-region~, ~kill-ring-save~, ~comment-or-uncomment-region~ and
  ~indent-region~ directly in ~vice-operator-alist~.
- [X] Extract the leading-digit count loop of ~vice-dispatch~ into a
  ~vice--read-count~ helper.
- [X] Replace the ~setq end~ in ~vice--thing-bounds~ with a ~let~ that
  computes the final ~end~ directly.
- [X] Test helpers repeat ~with-temp-buffer~ / ~emacs-lisp-mode~ /
  ~insert~ / ~goto-char~ in ~8 places; fold into one
  ~vice-test--with-buffer~ macro.

** Ideas

Directions from a usefulness/ergonomics critique. vice's edge over
native Emacs (~C-M-u C-M-k~, ~M-h~, ~C-M-h~) and ~change-inner~ /
~expreg~ / ~embrace~ is thin today; these aim to widen it.

*** Cheap wins

- [X] Pulse the resolved region after applying
  (~pulse-momentary-highlight-region~), so ~y~ shows what was copied.
- [ ] Object aliases in the style of targets.vim, so the common cases
  need no Shift: ~q~ any quote (~(:string nil)~, already supported),
  ~b~ for ~(~, ~B~ for ~{~.
- [ ] ~?~ in ~vice-dispatch~ lists the operators and objects.
- [ ] Signal a ~user-error~ when a count is given to an object that
  ignores it (~w~ ~s~ ~p~ ~f~ and strings), instead of silently
  dropping it.

*** Differentiators

- [ ] Region commands as operators: when an operator is an interactive
  command, set the region and ~call-interactively~ it, so any
  ~*-region~ command plugs in. Candidate defaults Vim lacks: narrow,
  fill, up/downcase, eval-region, shell-command-on-region (filter),
  query-replace inside the object, align.
- [ ] Seek forward (targets.vim): when point is not inside the object,
  use the next one on the line; optional ~n~ / ~l~ modifiers for
  next/last.
- [ ] Change/delete surrounding delimiters (~cs"'~, ~ds(~), which
  complements the wrap operator.
- [ ] Repeat the last operation via ~repeat-mode~ or a
  ~vice-repeat~ command.

*** Later

- [ ] Remote operations: act on an object at an ~avy~ target without
  moving point.
- [ ] Repeated ~v a m~ grows the selection outward, like ~expreg~.
- [ ] More objects: line, buffer, comment; argument and tag via
  tree-sitter.
- [ ] Buffer-local operators and objects per major mode (e.g. ~$~ for
  LaTeX math).
